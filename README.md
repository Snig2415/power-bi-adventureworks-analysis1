# Power BI AdventureWorks Analysis

## Project Overview

A Power BI portfolio project exploring business performance using the AdventureWorks sample dataset. The project demonstrates data preparation, data modeling, DAX calculations, and interactive business intelligence reporting.

## Objectives

* Import and transform data using Power Query.
* Explore data quality and prepare data for analysis.
* Develop a structured data model.
* Create analytical measures using DAX.
* Build interactive reports and visualizations.
* Communicate business insights through data analysis.

## Tools and Technologies

* Microsoft Power BI Desktop
* Power Query
* DAX
* Git and GitHub

## Project Status

**In progress:** Currently learning data import and transformation. Data modeling, DAX measures, and dashboard development will follow.

## Planned Repository Structure

* `data/` — dataset information and access instructions.
* `documentation/` — data preparation, data dictionary, and business insights.
* `powerbi/` — Power BI report files.
* `screenshots/` — dashboard screenshots.

## Data Source

AdventureWorks sample dataset used for educational and portfolio purposes. The specific dataset version and source will be documented as the project develops.
